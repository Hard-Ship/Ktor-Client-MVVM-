# Ktor Client Todo App

A Android Todo application built to learn and practice Ktor Client framework for API communication.

## Tech Stack

- Kotlin
- Jetpack Compose
- Ktor Client
- Kotlin Serialization
- Coroutines
- StateFlow
- MVVM Architecture

## API

DummyJSON API for practicing REST operations.

API Base URL:

https://dummyjson.com/
